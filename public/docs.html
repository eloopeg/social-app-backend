Eloop Social API

A simple REST API for authentication, profiles, posts, likes, comments, replies, follows, and notifications.

Base URL: https://social-app-backend-6u7v530f9-eloopeg.vercel.app/api
Quick startAuthUsersPostsCommentsNotificationsErrors

Quick start

Register, copy data.token, then send it with protected requests.

Authorization: Bearer YOUR_TOKEN
Content-Type: application/json
The public health check is /api/health.

Authentication

MethodEndpointPurposeAuth
POST/users/signupCreate account and return JWTNo
POST/users/signinSign in by email or usernameNo
PATCH/users/change-passwordChange passwordYes

Signup body

{
  "name": "Ahmed Test",
  "username": "ahmedtest123",
  "email": "ahmedtest123@example.com",
  "password": "Test123456"
}

Signin body

{
  "login": "ahmedtest123",
  "password": "Test123456"
}

Users

MethodEndpointPurposeAuth
GET/usersGet usersNo
GET/users/:idGet one userNo
GET/users/profile-dataGet current profileYes
PUT/users/:idUpdate own profileOwner
POST/users/:id/followFollow userYes
DELETE/users/:id/followUnfollow userYes

Posts

MethodEndpointPurposeAuth
GET/posts?page=1&limit=10List postsYes
GET/posts/:postIdGet one postYes
POST/postsCreate postYes
PUT/posts/:postIdUpdate own postOwner
DELETE/posts/:postIdDelete own postOwner
PUT/posts/:postId/likeLike or unlikeYes
PUT/posts/:postId/bookmarkBookmark toggleYes
POST/posts/:postId/shareShare postYes
POST /api/posts

{
  "body": "Hello from Eloop",
  "image": "https://example.com/image.jpg"
}

Comments and replies

MethodEndpointPurposeAuth
GET/posts/:postId/commentsGet commentsYes
POST/posts/:postId/commentsAdd commentYes
GET/posts/:postId/comments/:commentId/repliesGet repliesYes
POST/posts/:postId/comments/:commentId/repliesAdd replyYes
PUT/posts/:postId/comments/:commentIdEdit commentOwner
DELETE/comments/:idDelete commentOwner
POST /api/posts/POST_ID/comments

{
  "content": "Great post!"
}

Notifications

MethodEndpointPurposeAuth
GET/notifications?page=1&limit=10List notificationsYes
GET/notifications/unread-countUnread countYes
PATCH/notifications/:notificationId/readMark one readYes
PATCH/notifications/read-allMark all readYes

Responses and errors

Success: { "success": true, "message": "success", "data": {}, "meta": {} }
Error:   { "success": false, "message": "Error message" }

Common status codes: 400 invalid data, 401 invalid token, 403 forbidden, 404 not found, 409 duplicate data, 503 database unavailable.
